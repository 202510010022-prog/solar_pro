# Notas da Versao - Solar Pro 0.1.0

Primeira versao de teste do Solar Pro para Android.

## Novidades

- Login com usuarios autorizados.
- Dashboard com resumo comercial e financeiro.
- Cadastro e listagem de clientes.
- Gestao de projetos por status.
- Dimensionamento fotovoltaico com consumo mensal.
- Area financeira com cobrancas e pagamentos.
- Exportacao de relatorios de projetos.
- Sincronizacao com Supabase.

## Observacoes para testadores

- Esta versao e destinada a validacao interna.
- Relate problemas de login, sincronizacao, valores financeiros ou telas
  quebradas.
- Alguns dados podem ser ficticios durante o periodo de teste.
