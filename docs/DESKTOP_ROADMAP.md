# Futuro do Desktop - CRM Completo

## Contexto

O `mobile_app` e a ferramenta agil de campo do Solar Pro, focada em dimensionamento, PVGIS, orcamento rapido e cadastro de clientes.

O `desktop_app` / `desktop_app_qt` sera desenvolvido no futuro como um CRM completo, voltado para uma gestao mais robusta do negocio.

## Status Atual

O desenvolvimento do desktop esta pausado.

Todo o esforco atual esta focado em deixar o `mobile_app` pronto para lancamento comercial primeiro.

## Quando Retomar

O desktop deve ser retomado depois que o `mobile_app` estiver publicado e estavel em uso real.

## Nota Tecnica Pendente

Quando o desktop for retomado, sera necessario decidir se o `desktop_app` (Python/Tkinter ou similar) e o `desktop_app_qt` (PyQt) continuam como dois codigos separados ou se um deles sera descontinuado em favor do outro.

Isso ainda nao foi decidido e deve ser revisado antes de investir no CRM completo.
