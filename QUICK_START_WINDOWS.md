## 🚀 Como Fazer Executável para Windows (Guia Rápido)

### **Versão Super Rápida (Copiar para outro PC)**

```
1. Abra este arquivo no Windows:
   👉 build_windows.bat (duplo clique)
   
2. Escolha opção "1" no menu
   
3. Pronto! Seu arquivo está em:
   ✅ dist/SolarPro.exe
   
4. Copie esse arquivo para qualquer PC Windows
```

**Fim!** Você tem um executável que funciona em qualquer Windows.
